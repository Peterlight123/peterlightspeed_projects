# PeterLightspeed Projects

Source code for my Python, Go, AI, and web development tutorials and live coding sessions.

## Overview

This repository collects the code behind my tutorials and live coding sessions, covering a range of topics across Python, Go, AI, and web development. It's meant as a learning resource for anyone following along or exploring similar topics on their own.

## Features

- Tutorial source code organized by topic/session
- Examples spanning Python, Go, and AI
- Practical, beginner-to-intermediate friendly code samples

## Tech Stack

- Python
- Go

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/peterlightspeed/peterlightspeed_projects.git
   cd peterlightspeed_projects
   ```
2. Browse the folders for the tutorial or session you're interested in, and follow any per-folder instructions (e.g. `requirements.txt` for Python examples or `go.mod` for Go examples).
